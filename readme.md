# KoishiPlugin-QQMudae

基于 **Koishi** 的群聊角色抽卡与收集插件。

通过每日签到获取金币，使用金币抽取角色，并通过图鉴、人气排行与角色出售构成基础收集玩法。

同一群内，每个角色同时只能属于一名玩家。抽卡时会自动排除自己或群友已经拥有的角色，因此不会因为重复角色浪费一次抽卡。

> 当前版本：**v1.0.1**

> 本项目为非官方同人项目，与 Mudae、Bangumi 等项目不存在官方关联。

---

## ✨ 功能

### 🎴 抽卡

使用：

```text
抽卡
```


每次抽卡消耗一定数量的金币。

抽卡时会自动排除：

* 自己已经拥有的角色
* 当前群其他成员已经拥有的角色

成功抽到角色后：

* 角色自动加入个人图鉴
* 角色人气计入个人总人气
* 更新当前群排名
* 显示角色当前出售价值

---

### 💰 每日签到

使用：

```text
签到
```

或：

```text
每日
```

每天可以签到一次并领取金币。

默认配置：

```text
每日签到：100 金币
单次抽卡：100 金币
```

因此默认情况下，每天签到可以获得约一次抽卡所需的金币。

---

### 💳 查看余额

使用：

```text
余额
```

可以查看：

* 当前金币
* 图鉴总人气
* 已收录角色数量
* 当前群排名

私聊中不会显示群排名。

---

### 📖 图鉴

使用：

```text
图鉴
```

查看指定页：

```text
图鉴 2
```


图鉴会显示：

* 当前金币余额
* 图鉴总人气
* 当前群排名
* 已收录角色数量
* 角色名称
* 角色 ID
* 角色人气
* 当前出售价值

每页显示 10 个角色。

---

### ♻️ 出售角色

使用：

```text
出售 <角色ID>
```

例如：

```text
出售 12393
```

出售后：

* 角色从自己的图鉴中移除
* 玩家总人气下降
* 获得对应金币
* 该角色重新回到当前群的可抽取卡池

出售价格根据角色人气计算，并受到最低和最高价格限制。

默认计算方式大致为：

```text
出售价格 = 最低价格 + √角色人气 × 人气系数
```

然后限制在配置的最低与最高出售价格之间。

默认情况下，普通出售无法完整返还一次抽卡所需的金币，以避免形成无限的：

```text
抽卡 → 出售 → 抽卡 → 出售
```

正收益循环。

---

### 🏆 群排行

使用：

```text
排行
```

或：

```text
群排行
```

显示当前群图鉴总人气 Top 10。

相同总人气采用并列排名，例如：

```text
1. Alice：5000
1. Bob：5000
3. Carol：4200
```

排行只在群聊中可用。

---

```text
帮助
```

```text
菜单
```

## ⚙️ 配置

插件支持直接在 **Koishi 控制台**中调整经济参数，无需修改源码。

| 配置项               |             默认值 | 说明        |
| ----------------- | --------------: | --------- |
| `drawCost`        |           `100` | 单次抽卡消耗金币  |
| `dailyReward`     |           `100` | 每日签到奖励    |
| `sellPriceMin`    |            `10` | 最低出售价格    |
| `sellPriceMax`    |            `90` | 最高出售价格    |
| `sellPriceFactor` |           `1.3` | 出售价格的人气系数 |
| `timezone`        | `Asia/Shanghai` | 每日签到使用的时区 |

## 👥 数据隔离

玩家与角色归属按照：

```text
platform + guildId
```

进行隔离。

因此：

* 不同群之间的角色归属互不影响
* 同一个角色可以在不同群分别被不同玩家拥有
* 同一群内，同一个角色同时只能属于一个玩家
* 出售角色后，该角色重新进入当前群卡池
* 私聊使用独立的数据作用域
* 私聊不会参与群排行

---

## 🗄️ 数据库

插件当前主要使用两张数据表。

### `mudae_player`

保存玩家状态：

```text
platform
guildId
userId
username
totalHeat
coins
lastDailyDate
```

主要用于记录：

* 玩家身份
* 金币
* 图鉴总人气
* 每日签到状态

### `mudae_claim`

保存角色归属：

```text
platform
guildId
characterId
userId
claimedAt
```

用于记录某个角色当前属于当前群中的哪一位玩家。

## 👤 角色数据

插件内置约一万五千名角色的数据。

角色数据主要包含：

```json
{
  "id": 12393,
  "name": "牧濑红莉栖",
  "heat": 4176,
  "image": [
    "https://example.com/image.jpg"
  ]
}
```

主要字段：

| 字段      | 说明       |
| ------- | -------- |
| `id`    | 角色唯一 ID  |
| `name`  | 角色显示名称   |
| `heat`  | 角色人气     |
| `image` | 角色图片 URL |

部分原始数据还可能包含别名、性别等附加信息。

角色数据由 `CharacterManager` 在插件启动时加载。

## 🛠️ 开发


